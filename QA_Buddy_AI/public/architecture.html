Technology Stack

LLM GROQ

Mixtral-8x7b-32768 for answer generation. 32K context window, sub-100ms TTFT, free tier available. Streaming via Server-Sent Events.

Embeddings OpenAI

text-embedding-3-small (768-dim). Chosen over bge-m3 for Vercel compatibility — no local model to load. $0.02/1M tokens.

Vector DB Qdrant Cloud

Managed vector database with built-in cosine similarity. Free tier includes 1GB storage. Single-container REST API.

Backend Flask + Python 3.12

Vercel Python serverless runtime. 6 API endpoints: health, chat (SSE), settings, JIRA test, sources, ingestion trigger.

Frontend React 19 + Vite

TypeScript SPA with streaming chat UI, ReactMarkdown rendering, cited source cards, settings panel. Built with Vite 6.

Ingestion Local Script

scripts/seed_qdrant.py chunks files per-type (code by function, CSV per-row, MD by heading, text by sliding window), embeds via OpenAI, upserts to Qdrant Cloud.

Chunking Strategy

📁 Code (py/java/js/ts)

  • Semantic: per function/class boundary
  • Zero overlap — code is meaningless mid-function
  • Preserves docstrings and imports

📁 CSV Test Cases

  • One row = one chunk
  • Header row preserved per chunk
  • Atomic — never split a test case

📁 Markdown Docs

  • Per heading (## / ###) boundaries
  • Respects document structure
  • Fallback to sliding window (768/150)

📁 Generic (txt/log/pdf)

  • Sliding window: 768 chars, 150 overlap
  • Smaller for logs: 512 chars, 100 overlap
  • Full content via PyMuPDF for PDFs

API Endpoints

GET /api/health

System status: GROQ, OpenAI, Qdrant, JIRA connectivity checks. Returns 200 when API is alive.

POST /api/chat

Main query endpoint. Accepts {query, history}, returns SSE stream with tokens + source citations.

GET /api/settings

Read-only config status. Shows which services are configured (keys masked).

POST /api/jira/test

Test JIRA connection with custom JQL. Returns first 5 issues or error message.
